# Riya Patel — Aerospace Engineering Portfolio

A responsive, single-page portfolio website built with plain HTML, CSS and JavaScript. It is designed to be hosted for free using GitHub Pages.

## Files
- `index.html` — content and page structure
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation, project detail panels and scroll reveals

## Before publishing
1. Open `index.html`.
2. Find `YOUR_EMAIL@example.com` and replace it with the email address you want to publish. If you do not want to publish an email address, replace the `mailto:` link with your preferred contact method.
3. Check every project description and update it as your work progresses.
4. Add your own project evidence. The project artwork is CSS illustration; replace it with your own CAD screenshots, photographs and diagrams when ready.
5. Check dates and award titles against your certificates.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for the deployment to finish. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io`.

## Notes
- Google Fonts are loaded online. The site still works if they are unavailable, using fallback fonts.
- No build tools, frameworks or paid services are required.
- The page is mobile responsive and includes reduced-motion support.
- The current contact email is a placeholder and must be changed before launch.
